\begin{definition}\label{1.2.20}
	Let $M$ be a smooth manifold. Define the \emph{tangent bundle} $TM$ as the disjoint union
	\[
		TM\coloneqq \coprod_{p\in M} T_pM
	.\]
\end{definition}

The motivation here is smooth vector fields. There is a projection $TM\to M$ by mapping each $v\in T_pM\subseteq TM$ to $p$:
\[
	\pi : T_pM \mapsto p
.\]
If we give $TM$ a smooth structure, we can define some $V : M \to TM$ to be a smooth vector field if $\pi \circ V=1$.

\begin{proposition}\label{1.2.21}
	For any smooth $n$-manifold $M$, the tangent bundle has a natural smooth structure making it a $2n$-manifold, and the canonical projection $\pi : TM \to M$ is smooth.
\end{proposition}
