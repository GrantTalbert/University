I learned something. The conjugation action $C_g : h\mapsto ghg^{-1} $ induces $\mathrm{Ad} _g$ via $\mathrm{Ad} _g=\mathrm{d} C_g$. Then this determines $G\to \End(\mathfrak{g} )$ via $g\mapsto \mathrm{Ad}_g$, and the differential of this is $\mathrm{ad}_X$.

\[
	\mathrm{d} e^X = \sum_{n\geq 0} \sum_{k=0}^{n-1} \frac{X^k\cdot \mathrm{d} X\cdot  X^{n-k-1} }{n!} 
.\]
I think here $X$ is a matrix. Then this is
\[
	\int_0^1 e^{(1-t)X} \mathrm{d} Xe^{tX}  \,\mathrm{d} t
.\]
or something.
