	\item I will use the formula $(\Delta M)^2=\left\langle M^2 \right\rangle -\left\langle M \right\rangle ^2$, because I feel like it. First, we compute $M^2$. Since $M$ is a measurement operator, it is Hermitian. Moreover, since we are using an orthonormal set of eigenvectors, $\braket{m_i}{m_j} =\delta_{ij} $, and thus
		\begin{align*}
			M&=\sum_{i} m_i \ket{m_i} \bra{m_i}\\
			\implies M^2 &= \left( \sum_{i} m_i \ket{m_i} \bra{m_i}  \right) ^2\\
				     &=\sum_{i}\left( m_i \ket{m_i} \bra{m_i} \sum_{j} m_j\ket{m_j} \bra{m_j}  \right) \\
				     &=\sum_{i} m_i^2 \ket{m_i} \braket{m_i}{m_i} \bra{m_i} \\
				     &=\sum_{i} m_i^2 \ket{m_i} \bra{m_i}
		.\end{align*}

# check if all list elements r same
def all_same(vals):
    first = vals[0]
    return all(np.allclose(x, first) for x in vals) # thanks chatgpt

def is_ev(v):
    mat = H @ v
    vals = []
    for i in range(1, len(v)):
        # handle div by 0
        if v[i, 0] == 0:
            if mat[i, 0] != 0:
                print("failed")
                return False
        else:
            vals.append(mat[i, 0] / v[i, 0])

        return vals[0]
    else:
        print("failed")
        return False

\item The vectors span the space if and only if
	\[
		c_1 \ket{v_1} +c_2 \ket{v_2} +c_3 \ket{v_3} +c_4 \ket{v_4} 
	\]
	implies $c_i=0$ for all $i$. Equivalently, the equation
		\[
			\begin{pmatrix}
	\ket{v_1}  & \ket{v_2}  & \ket{v_3}  & \ket{v_4} 
	\end{pmatrix}\ket{c}=0
		\]
		is solved if and only if $\ket{c} =0$. For simplicity, call the matrix of kets $V$. This happens if and only if $\ker V$ is trivial; i.e. the linear map given by the matrix is injective, and thus is bijective since our space is 4-dimensional. It follows that $V$ must have rank 4, which can be computed by numpy.
