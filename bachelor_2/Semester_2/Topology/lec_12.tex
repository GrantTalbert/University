We can define an equivalence relation $\sim $ on a topological space such that $x\sim y$ iff there exists a \emph{connected} set $C\subseteq X$ such that $x,y\in C$. The only nontrivial property is transitivity, and this follows immediately from the previous theorem.

\begin{definition}[Locally Connected]\label{dfn:4.2}
	A space $X$ is locally connected if for all $x\in X$, there exists a connected open neighborhood $x\in C\subseteq X$.
\end{definition}

\begin{theorem}\label{thm:4.4}
	Given the equivalence relation above, each element of $X/\sim $ is connected in $X$. Moreover, for every $A\subseteq X$ connected, there exists $[x]$ with $A\subseteq [x]$, and each $[x]$ is closed. If $X$ is locally connected, then each component is open.
\end{theorem}
