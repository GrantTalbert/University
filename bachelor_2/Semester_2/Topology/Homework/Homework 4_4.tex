Note that each element of the Cantor set can be identified with a sequence $\left\{ a_i \right\}_{i=1} ^\infty $, with notation as in the handout. We can then define a corresponding sequence $\left\{ b_i \right\}_{i=1} ^{\infty } $, where $b_i=0$ if $a_i=0$, and $b_i=1$ if $a_i=2$. We can then define a map $\varphi : \mathcal{C}  \to [0,1]$ as the function
\[
	\sum_{i=1}^{\infty} a_i3^{-i} \mapsto \sum_{i=1}^{\infty} b_i2^{-i} 
.\]

Now we show surjectivity. Let $x\in [0,1]$. Define the series $\left\{ x_i \right\}_{i=1} ^{\infty } $ such that
\[
	x_{i} \coloneqq 
	\begin{cases}
		1,&x\geq 2^{-i} +\sum_{j=1}^{i-1} x_i2^{-i} \\
		0,&\text{otherwise} 
	\end{cases}
.\]
It's immediately obvious that there exists a preimage of this series in $\mathcal{C} $, so it suffices to show $x_i\to x$. If $x=0$, then we obviously have $x_i=0$ converges to $x$, and if $x=1$, then
\[
	\sum_{i=1}^{\infty} 2^{-i} =\frac{1/2}{1-1/2} =\frac{1/2}{1/2} =1
.\]
Therefore, without loss of generality let $x\in (0,1)$. Let $U\subseteq (0,1)$ be an open neighborhood of $x$, and by definition of a basis there exists $r$ such that $B_r(x)\cap (0,1)\subseteq U$. Without loss of generality, we can take $B_r(x)\subseteq (0,1)$ by taking $r<\min (d(x,0),d(x,1))$. It suffices to show that there exists $n$ such that $\sum_{i=1}^{n} x_i2^{-i}\in B_r(x)$, and that
\[
	d\left( \sum_{i=1}^{n} x_i2^{-i} ,x \right) \leq d\left( \sum_{i=1}^{n+1} x_i2^{-i}  \right) 
\]
for all $n$.

First, note that by definition, $d(x_1,x)\leq 2^{-1} $. Now suppose that for some $n$,
\[
	d\left( \sum_{i=1}^{n} x_i2^{-i},x \right) \leq 2^{-n} 
.\]
If we also have that
\[
	d\left( \sum_{i=1}^{n} x_i2^{-i} ,x \right) \leq 2^{-n-1} ,
\]
then by definition $x_{n+1} =0$, and we are done. Otherwise, we have $x_{n+1} =1$, and noting that the partial sum will always be less than $x$ by definition, we have
\begin{align*}
	2^{-n}\geq  x-\sum_{i=1}^{n} x_i2^{-i} > 2^{-n-1} &\implies 2^{-n} -2^{-n-1} \geq x-\sum_{i=1}^{n+1} x_i2^{-i} >2^{-n-1} -2^{-n-1} \\
							  &\implies 2^{-n} \left( 1-2^{-1}  \right) \geq d\left( \sum_{i=1}^{n+1} x_i2^{-i} ,x \right)  >0\\
							  &\implies 2^{-n} \left( 2^{-1}  \right) \geq d\left( \sum_{i=1}^{n+1} x_i2^{-i} ,x \right) >0\\
							  &\implies 2^{-n-1} \geq d\left( \sum_{i=1}^{n+1} x_i2^{-i}  \right) >0
.\end{align*}
By induction, we thus have
\[	d\left( \sum_{i=1}^{n} x_i2^{-i} ,x \right) \leq 2^{-n} 
\]
for all $n$. It is weasily shown that for all $r\in\mathbb{R} ^+$, there exists $n$ such that $r>2^{-n} $. Therefore, there exists some $n$ such that
\[
	\sum_{i=1}^{n} x_i2^{-i} \in B_r(x)
.\]

Second, by our previous proof note that for any $n$, we have either
\[
	d\left( \sum_{i=1}^{n} x^i2^{-i} ,x \right) =d\left( \sum_{i=1}^{n+1} x^i2^{-i}  \right) ,
\]
and thus we have
\[
	d\left( \sum_{i=1}^{n} x^i2^{-i} ,x \right) \geq d\left( \sum_{i=1}^{n+1} x^i2^{-i}  \right) ,
\]
or we instead have
\[
	2^{-n} \geq d\left( \sum_{i=1}^{n} x_i2^{-i} ,x \right) \geq 2^{-n-1} \geq d\left( \sum_{i=1}^{n+1} x_2^{-i}  \right)  
.\]
Therefore, the distances are decreasing as $n\to \infty $. Therefore, there exists $N$ such that $N\leq n$ implies the partial sum
\[
	\sum_{i=1}^{n} x_i2^{-i} \in B_r(x)
.\]
Since $B_r(x)$ exists (WLOG) as a subset of any open set $U$, we have that the sequence of partial sums converges to $x$, and thus
\[
	\sum_{i=1}^{\infty} x_i2^{-i}=x
.\]

Before we can show continuity, we must show the following important lemma.
\begin{lemma}\label{lma:1.1}
	If $x,y\in \mathcal{C} $, then $x<y$ if and only if $\varphi (x)\leq \varphi (y)$.
\end{lemma}
\begin{proof}
Let $x<y$. It follows immediately that there exists at least one $i$ such that $x_i<y_i$. Let $n$ be the minimum over all such $i$, and note that we must have $y_n=2$ and $x_n=0$ by definition. We also have that
\[
	\sum_{i=n+1}^{\infty} x_i3^{-i} =\sum_{i=0}^{\infty} 3^{-n-1} x_{i+n+1}3^{-i} \leq \sum_{i=0}^{\infty} 2\cdot 3^{-n-1} \cdot 3^{-i} =\frac{2\cdot 3^{-n-1} }{1-\frac{1}{3} } =3^{-n} < 2\cdot 3^{-n} =y_n3^{-n} `
.\]
It follows that it literally doesn't matter what the remaining $x_i$ are from $n+1$ to $\infty $, as the single $y_n$ term in the summation is greater than the rest of the summation in $x$. It is obvious that this logic can be reversed to obtain the other direction of the implication. Therefore, $x < y$ in the Cantor set if and only if the largest $n$ such that $x_n\neq y_n$ has $x_n<y_n$.

Note that the action of our definition of $\varphi $ on the sequence $x_i$ is equivalent to mapping $x_i \mapsto x_i/2$. We thus have
\[
	\varphi (x)=\sum_{i=1}^{\infty} x_i2^{-i-1} 
.\]
We once again have
\[
	\sum_{i=n+1}^{\infty} x_i2^{-i-1} =\sum_{i=0}^{\infty} 2^{-n-2} x_{n+1+i} 2^{-i} \leq \sum_{i=0}^{\infty } 2^{-n-1} \cdot 2^{-i} =\frac{2^{-n-1} }{1-\frac{1}{2} } =2^{-n} 
.\]
Also note that
\[
	y_n2^{-n-1} =2^{-n} 
.\]
Therefore,
\[
	\sum_{i=n}^{\infty} x_i2^{-i-1} \leq y_n2^{-n-1} 
.\]
The change of starting indicies from $n+1$ to $n$ is since $x_n=0$. This shows that $\phi (x) \leq \phi (x)$ if and only if the largest $n$ such that $x_n\neq y_n$ has $x_n<y_n$, if and only if $x < y$ in $\mathcal{C} $. This completes the lemma. The strict $<$ relation in $\mathcal{C} $ for any nonequal series also suffices to show $\varphi $ is well-defined, by showing two distinct series cannot converge to the same number, which is a nontrivial result I have until now handwaved.
\end{proof}

\section*{Problem 3}
Let $X\subseteq \mathbb{N} $ be open. Then it has finite compliment. Suppose that $A,B\subseteq X$ are disjoint open sets such that $A \cup B=X $. Suppose for contradiction they are both nonempty. Since they are disjoint, $A\subseteq B^{c} $. Since $A$ has finite compliment, it must be infinite, as $\mathbb{N} $ is infinite and
\[
	\left| A  \right| =\left| X\setminus A^{c}  \right| =\left| X \right| \setminus \left| A^{c}  \right| =\left| X \right| 
,\]
since $\left| A^{c}  \right| $ is finite. However, since $B^{c} $ is finite, and $A\subseteq B^{c} $, it follows that $\left| A \right| \leq \left| B^{c}  \right| $, and thus $A$ is finite, a contradiction. Therefore, either $A$ or $B$ is empty, and every open subset $X\subseteq \mathbb{N} $ is connected. Therefore, $\mathbb{N} $ is locally connected.

Let $X\subseteq \mathbb{N} $ be open, and suppose that $f : [0,1] \to X$ is continuous. It suffices to show $f$ is constant, as we then have $f(0)=f(1)$, and thus for any $x\neq y$, there is no continuous function with $f(0)=x$ and $f(1)=y$. Such $x\neq y$ exist since $X$ is not finite, and thus cannot be a singleton.
\begin{lemma}\label{lma:3.1}
	If $U\subseteq B$ is closed and $f : A \to B$ is continuous, then $f^{-1} (U)$ is closed. In particular, $f^{-1} (A^{c} )=f^{-1} (A)^{c} $.
\end{lemma}
\begin{proof}
	Since $U^{c} $ is open, $f^{-1} (U^{c} )$ is open. For any $x\in f^{-1} (U^{c} )=f^{-1} (B\setminus U)$, we must have $f(x)\in U^{c} $, and thus $f(x)\notin U$. Therefore, $x\in f^{-1} (B)\setminus f^{-1} (U)$. Similarly, if $x\in f^{-1} (B)\setminus f^{-1} (U)$, then $f(x)\in B\setminus U$, so $x\in f^{-1} (B\setminus U)$. It follows that
	\[
		f^{-1} (U^{c} )=f^{-1} (B\setminus U)=f^{-1} (B)\setminus f^{-1} (U)=A\setminus f^{-1} (U)=f^{-1} (U)^{c} 
	.\]
	Therefore, $f^{-1} \left( U \right) $ is closed.
\end{proof}
Let $\left\{ x \right\} \subseteq \mathbb{N} $ be any singleton. Since it is finite, it must be closed, and thus $f^{-1} (x)$ is closed for any such $x$. For any $x\neq y$, we have $f^{-1} (x) \cap f^{-1} (y)=\varnothing $, since $f$ is well-defined. We can thus write $[0,1]$ as a disjoint union of closed sets
\[
	\bigcup_{n\in\mathbb{N} } f^{-1} (n)
.\]
\begin{lemma}\label{lma:3.2}
	Let $A$ be a connected space. Then there exists no finite collection of closed, disjoint, nonempty, proper subsets $\left\{ U_i \right\}_{i=1}^n$ of $A$ such that
	\[
		\bigcup_{i=1} ^nU_i=A
	.\]
\end{lemma}
\begin{proof}
	Note that if $U\cup V=A$ are closed sets, then $U=V^{c} $ and vice versa, and thus these sets are both closed and open. By a lemma done in class, we have that $U,V=A$. The statement then follows immediately from an elementary application of induction.
\end{proof}
This takes care of the case where finitely many $f^{-1} (n)$s are nonempty, since $[0,1]$ is connected. Suppose now for contradiction that infinitely many such fibers are connected. Since any two fibers $f^{-1} (n),f^{-1} (m)$ are disjoint, there then exist disjoint neighborhoods $U_n,U_m$ of $n$ and $m$ respectively, whos existence can be verified by finding the smallest distance between any two points of $f^{-1} (n)$ and $f^{-1} (m)$, and taking unions of open balls around each element of each respective fiber, with radii no more than half of that distance.

Choose distinct $n,m\in X$. Then with notation as before, let $I_n=[a,b]$ be a connected component of $[0,1]\setminus U_n$. Since $f^{-1} (n)\subseteq U_n$, we have that $I_n \cap U_n=\varnothing $. For all $a$ such that $f^{-1} (a)\cap U_n=\varnothing $, define $I_a\coloneqq I_n$. Since $U_n$ is connected, it follows that there must be infinitely many $a\in X$ such that $f^{-1} (a) \cap I_n\neq \varnothing $, otherwise by lemma \ref{lma:3.2}, $I_n$ would be disconnected, as $f^{-1} (a) \cap I_n$ is closed in $I_n$ for all $a$. This process can be repeated inductively by choosing new distinct $m,k$ such that $f^{-1} (m),f^{-1} (k) \cap I_n \neq \varnothing $, and taking $I_n$ instead of $[0,1]$.

This gives us a chain $\ldots \subseteq I_a\subseteq I_b\subseteq I_n$ with one $I_n$ for all $n\in X$, and by explicit construction each one has $I_n \cap f^{-1} (n)=\varnothing $. Moreover, each one is defined as an interval, and thus by the finite interval lemma
\[
	\bigcap_{n\in X} I_n\neq \varnothing 
.\]
There thus exists at least some $x\in I_n$ for all $n$, and thus $x\in [0,1]$. Since the fibers over $f$ form a partition of $[0,1]$, there exists precisely one $n\in X$ such that $x\in f^{-1} (n)$. Since $x\in I_n$, we have $x\in I_n \cap f^{-1} (n)$, contradicting the fact that $I_n \cap f^{-1} (n)=\varnothing $, as defined in the construction of $I_n$.

Therefore, $[0,1]$ cannot be partitioned into countably infinite disjoint nonempty proper closed sets, nor can it be partitioned into finitely many such sets. Therefore, all but one set must be empty, and a single fiber $f^{-1} (n)$ must be the entire interval $[0,1]$, thus proving that $f$ is constant.

y

Since $\sin (1/x)$ is continuous for $x>0$, we clearly have that the component $\left\{ (x,\sin (1/x))\mid x>0 \right\} $ is path-connected, and thus connected. Moreover, since line segments are connected in $\mathbb{R} $ and there exists a trivial homeomorphism, and since homeomorphisms preserve connectedness, we have that $ \left\{ 0 \right\} \times [-1,1]$ is connected. It suffices to show that both sets fall within the same connected component; that is, there exists $x$ in the first set and $y$ in the second and a connected subset containing $x$ and $y$. For notational purposes, let $A_x\coloneqq \left\{ (x,\sin 1/x)\mid x>0 \right\} $, and let $A_y=\left\{ 0 \right\} \times [-1,1]$.

We can view $\sin (1/x)$ as $\sin (g(x))$ for $g(x)=1/x$. This function is monotonically decreasing on the interval in question, so for any $x_1,x_2$, we have the image of the interval $g(x_1,x_2)=(1/x_2,1/x_1)$. Since $\sin $ is periodic with period $2\pi $,for any $x_1,x_2$ such that $g(x_2)\leq 2\pi g(x_1)$, it follows that $\sin $ will attain all values $[-1,1]$ on $(1/x_2,1/x_1)$. 

Note that for all $(0,y)\in A_y$, for all $r>0$, there exists some $x$ such that $d(x,y)<r$. We can then choose $x'$ to be $x/2\pi $, and we then have that $g(x)\leq 2\pi g(x')$, and thus $\sin $ attains all values on $(1/x',1/x)$. Since $d(x',y)<r$, it follows that there exists some $(x,\sin (1/x))\in B_r(0,y) \cap A_x$, since $\sin $ attains all values on the interval. Therefore, for all $(0,y)\in A_y$, and for all open balls $B_r(0,y)$, the intersection $B_r(0,y) \cap  A$ is nonempty.

Suppose now for contradiction that there exist two nonempty disjoint proper open sets $C_1,C_2$ such that $C_1 \cup C_2=A$. Since $A_x,A_y$ are connected, this clearly reduces to the case where $C_1=A_x$ and $C_2=A_y$, or more precisely, $C_1 \subseteq A_x$ and $C_2 \subseteq A_y$ are open. Since $A_x$ is open, it can be written as a union of open balls intersecting with $A$, and more precisely intersecting with $A_y$, since $C_2 \subseteq A_y$:
\[
	\left(\bigcup_{i\in I} B_{r_i} (x_i)\right) \cap A_y
.\]
However, as shown earlier, $B_{r_i} (x_i) \cap A_x\neq \varnothing $ for all $i$, and thus there exist $x\in B_{r_i} (x_i)\subseteq C_2$ such that $x\in A_x$, and thus $x\notin A_y$, a contradiction since $A_x$ and $A_y$ are disjoint.

Now suppose for contradiction that there exists a path $\varphi : [0,1] \to A$ from $y$ to $x$. This path exists if we contstrain our choice of $x,y$ to $A_x$ or $A_y$, so choose $y_0\in A_y$ and $x_0\in A_x$. We can parameterize $\varphi $ as a function $\varphi (t)=(x(t),y(t))$, where $x(t),y(t) $ are continuous, since they can be obtained by composing $\varphi $ with the natural projection product spaces are endowed with, which is canonically continuous. More explicitly, the diagram
\[\begin{tikzcd}[row sep = 1.5em, column sep = 5em]
	&&\text{[}0,1\text{]} \\
	\text{[} 0,1\text{]} \ar[urr, bend left, "x(t)"]\ar[drr, bend right, "y(t)"]\ar[r, dashed, "\varphi (t)=(x(t)\times y(t))"]&A\ar[ur, two heads]\ar[dr, two heads]\\
																   &&\text{[} -1,1\text{]} 
\end{tikzcd}\]
of continuous functions commutes.

Since we have $\varphi (0)=(0,y_0)$, and $\varphi (1)=(x_0,\sin (1/x_0)$, we must have $x(0)=0$, $x(1)=x_0$, $y(0)=y_0$, and $y(1)=\sin (1/x_0)$. Since $\mathbb{R} $ and it's open/closed subsets are Hausdorff, we have that singletons are closed, and thus by lemma 2, the preimage $x ^{-1} (t_0)$ for any singleton $\left\{ t_0 \right\} $ is closed. Define $t_0\coloneqq \sup x ^{-1} (0)$, and since the fiber of $0$ is closed, it must contain it's boundary (and thus it's sup), so $x(t_0)=0$.

If the function were to be continuous, we would ahve
\[
	\lim_{t \to t_0^-} \varphi (t)=\varphi (t_0)=(0,y(t_0))
.\]
However, as we have shown previously, every open ball centered at an element of $A_y$ contains elements of $A_x$, and if it were to converge anywhere, we would be able to define convergence at \emph{any} element of $A_y$. Since limits must converge uniquely or not at all in Hausdorff spaces, we must conclude the sequence does not converge, and the limit does not exist, and thus $\varphi $ is not continuous.

Let $X$ be Hausdorff and $A\subseteq X$ be compact. Fix $x\in A^{c} $. Since $X$ is Hausdorff, for all $y\neq x$, there exist disjoint open neighborhoods $x\in U_y$, $y\in V_y$. It follows that there exists an open cover $\left\{ V_y \right\}_{y\in Y} $ of $A$, and since $A$ is compact, there exists a finite subcover $\left\{ V_{y_i}  \right\}_{i=1}^n\subseteq \left\{ V_y \right\}_{y\in A} $ of $A$. We can then choose a corresponding collection $\left\{ U_{y_i} \right\}_{i=1} ^n$ with notation as before, and it follows that the set
\[
	\mathcal{U}_x \coloneqq \bigcap_{i=1}^n U_{y_i}
\]
is open, since finite intersections of open sets are open. Since $V_{y_i} \cap U_{y_i} =\varnothing $, we have that $\mathcal{U} \cap V_{y_i} =\varnothing$ for all $i$. We then have
\[
	\mathcal{U}_x \cap \bigcup_{i=1}^n V_{y_i} =\varnothing \implies  \mathcal{U}_x \subseteq \left( \bigcup_{i=1}^n V_{y_i}  \right) \subseteq A^{c} 
.\]
With notation as before, we have
\[
	A^{c} =\bigcup_{x\in A^{c} } \mathcal{U}_x
.\]
Since this is a union of open sets, $A^{c} $ is open, and thus $A$ is closed.
