\lecture{6}{Mon 11 Nov 2024 11:39}{Balls and Boxes}

We have a set of boxes, which are either the same (same color), or different (diff colors). We then have a set of balls, which are numbered. Based on their numbering, they are either distinct or identical. We then have $(B,c)$ is a set $B$ with a color $c$. $S$ is the set of all $(B,c)$. Each set $B$ has balls, which are indicated by number.
